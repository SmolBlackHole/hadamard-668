# Security policy

Parent: [Project README](README.md)

Security fixes target the current development version. There is no separate
maintenance commitment for older snapshots.

For a vulnerability, use GitHub's private vulnerability reporting option on the
repository's Security tab if it is available. Otherwise, open an issue requesting
a private contact channel without disclosing the vulnerability itself. Do not put
credentials, private data or exploit details in a public issue.

Include the affected commit, Python version, platform and the smallest safe
reproduction in the private report.
